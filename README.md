# 情報とは「不確実性を減少させるもの」であることのシミュレーション

## 氏名

石井 淳也

---

# 概要

本課題では，「情報とは何か」という問いに対し，自分なりの定義を数学的に表現し，Pythonによるシミュレーションを用いてその妥当性を検証する。

本研究では，

> **「情報とは，不確実性を減少させ，複数の候補を区別可能にするものである。」**

と定義する。

例えば，ある事象について何も知らない状態では，多くの候補が存在するため不確実性は大きい。一方，何らかの観測を行うことで候補が絞り込まれると，不確実性は減少する。この「候補を絞り込む能力」こそが情報であると考える。

この考え方を確認するため，本課題では通信路をモデル化したシミュレーションを行う。

送信者は複数のメッセージ候補から一つを選択し，通信路を介して受信者へ送信する。通信路では一定確率でビット反転が発生するものとし，受信者はハミング距離が最小となるメッセージを推定する。

ノイズ率を変化させながら，

- 正答率
- 条件付きエントロピー
- 相互情報量
- 推定の曖昧さ

を評価し，情報と不確実性の関係について考察する。

---

# 情報の定義

本課題では，

> **情報とは，不確実性を減少させ，対象を区別可能にするものである。**

と定義する。

例えば，8通りの候補が存在するとき，観測前にはどれが正しいか分からない。

```
A
B
C
D
E
F
G
H
```

しかし観測後，

```
D
```

だけに候補が絞られたなら，

観測によって

- 候補数が減少した
- 不確実性が減少した

と言える。

したがって，観測によって減少した不確実性を情報として考える。

---

# 数学的定義

送信されるメッセージを確率変数

\[
M
\]

とする。

メッセージは

\[
N
\]

種類存在すると仮定する。

本課題では各メッセージは等確率で送信されるものとするため，観測前の不確実性（情報エントロピー）は

\[
H(M)
=
-\sum_{i=1}^{N}
P(M_i)\log_2P(M_i)
=
\log_2N
\]

となる。

本シミュレーションでは

\[
N=8
\]

であるため，

\[
H(M)=3\text{ bit}
\]

となる。

受信者が推定したメッセージを

\[
\hat{M}
\]

とすると，観測後に残る不確実性は条件付きエントロピー

\[
H(M|\hat{M})
\]

で表される。

このとき，観測によって得られた情報量を

\[
I(M;\hat{M})
=
H(M)-H(M|\hat{M})
\]

と定義する。

この式より，

- 観測前の不確実性
- 観測後の不確実性

の差が情報量となる。

すなわち，本課題では

**情報とは「不確実性の減少量」である**

という考え方を採用する。
