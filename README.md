# 1. 概要
本課題では，「情報とは何か」という問いに対して，自分なりの定義を与え，その考え方を数学的に定式化するとともに，Pythonを用いたシミュレーションによってその妥当性を検証する。


近年，「情報」という言葉は通信，インターネット，人工知能，画像認識など様々な分野で利用されている。
しかし，日常生活で使われる「情報」と，情報理論で扱われる「情報」は必ずしも同じ意味ではない。

例えば，ニュース記事やQRコードには多くのデータが含まれているが，それらが情報として価値を持つのは，「受け取る人が知らなかったことを知ることができる」という性質があるためである。

本課題では，
> **「情報とは，不確実性を減少させ，複数の候補を区別可能にするものである。」**

と定義した。

この考え方を確認するため，本課題では通信路をモデル化したシミュレーションを作成する。
送信者は複数のメッセージ候補の中から一つを送信し，通信路では一定確率でビット反転が発生するものとする。
受信者はハミング距離を用いて元のメッセージを推定し，ノイズ率を変化させながら以下の指標を評価する。

- メッセージの推定正答率
- 条件付きエントロピー
- 相互情報量
- 推定の曖昧さ
  
これらを比較することで，「情報」と「不確実性」の関係について考察する。

# 2. はじめに
私たちは日常生活の中で，「情報」という言葉を頻繁に使用している。

例えば，

- 試験結果を確認する
- QRコードを読み取る
- AIが画像を認識する

しかし，これらに共通する「情報」とは何であろうか。

例えば，試験結果を見る前には，
- 合格
- 不合格
  
という二つの可能性が存在している。

結果を見ることで，
```
合格
```
という一つの状態に確定する。

つまり，「候補が減少した」と言い換えることができる。

同様に，QRコードを読み取る前には，「どのURLが格納されているのか」は分からない。

しかし，読み取り後には，
```
https://example.com
```
という一つの文字列に確定する。

このように，人は観測を行うことで，未知であった対象を知ることができる。

本課題では，この「観測によって候補数が減少する」
という現象に着目した。

候補数が減少するということは，「不確実性が減少した」と言える。

そこで本課題では，
> **情報とは，不確実性を減少させ，対象を区別可能にするものである。**

という定義を採用する。

# 3. 情報の数学的定義
送信されるメッセージを確率変数\[M\]とする。

本シミュレーションでは，\[N\]種類のメッセージが存在し，各メッセージは等確率で送信されるものとする。

観測前の不確実性は，シャノンの情報エントロピーによって\[H(M)=-\sum_{i=1}^{N}P(M_i)\log_2P(M_i)\]で定義される。

各メッセージは等確率であるため，\[P(M_i)=\frac1N\]となり，\[H(M)=\log_2N\]となる。

本シミュレーションでは，
- メッセージ数：8種類

としたため，\[H(M)=\log_28=3\text{ bit}\]となる。

この値は，「観測を行う前には3 bit分の不確実性が存在する」ことを意味する。

次に，受信者が推定したメッセージを\[\hat{M}\]とする。

通信路にノイズが存在すると，受信者は必ずしも正しいメッセージを推定できるとは限らない。

そのため，観測後にも不確実性が残る。

この残った不確実性を条件付きエントロピー\[H(M|\hat{M})\]と呼ぶ。

一方，本課題では，「観測によって減少した不確実性」を情報として考える。

したがって，得られた情報量を\[I(M;\hat{M})=H(M)-H(M|\hat{M})\]と定義する。

この式から分かるように，
- 観測前の不確実性
- 観測後に残った不確実性

との差が情報量となる。

ノイズが存在しない場合，\[H(M|\hat{M})=0\]となるため，\[I(M;\hat{M})=3\text{ bit}\]となる。

一方，ノイズが増加すると，受信者は正しいメッセージを識別しにくくなる。

その結果，
- 条件付きエントロピーは増加する
- 相互情報量は減少する
ことが予想される。

本シミュレーションでは，この関係を実際に確認する。


# 4. シミュレーションの目的
本課題では，「情報とは不確実性を減少させるものである」という考え方を，通信路をモデル化したシミュレーションによって検証することを目的とする。

通信では，送信者がメッセージを送信し，受信者がその内容を推定する。

しかし，実際の通信路ではノイズが発生するため，受信者は常に正しいメッセージを受け取れるとは限らない。

ノイズが増加すると，
- 正しいメッセージを推定できる確率
- メッセージを区別できる能力
- 得られる情報量

はどのように変化するのだろうか。

もし，本課題で定義した
> 「情報とは，不確実性を減少させるものである。」

という考え方が正しいのであれば，ノイズが増えるにつれて，
- 情報量は減少する
- 不確実性は増加する
- 候補の区別が難しくなる

という結果になるはずである。

本シミュレーションでは，この仮説を検証する。

# 5. シミュレーション方法

## 5.1 メッセージの生成

まず，8種類のメッセージを準備する。

各メッセージは16bitのビット列で表現する。

さらに，各メッセージ同士のハミング距離が十分大きくなるように生成する。

ハミング距離が大きいほど，各メッセージは互いに区別しやすくなる。

例えば，
```
M0 : 0010110011010010

M1 : 1110000100111001

M2 : 0101101110010100

・・・
```
のようなビット列を生成する。


---

## 5.2 通信路
通信路では，各ビットが独立に確率\[p\]で反転するものとする。

例えば，
```
送信

10110011
```
が
```
受信

10100011
```
となれば，3番目のビットだけが反転したことになる。

ノイズ率\[p\]は0.00から0.50まで変化させる。


---

## 5.3 メッセージの推定

受信者は，受信したビット列とすべてのメッセージとのハミング距離を計算する。

ハミング距離とは，異なるビット数のことである。

例えば，
```
10101010

10101110
```
では，1bitだけ異なるため，ハミング距離は1となる。

受信者は，ハミング距離が最も小さいメッセージを送信されたメッセージとして推定する。


---

## 5.4 評価指標
本課題では，以下の4つを評価する。

### (1) 正答率
送信したメッセージを正しく推定できた割合である。

正答率が高いほど，情報が正しく伝達されたことを意味する。


---
### (2) 条件付きエントロピー
受信後にも残る不確実性を表す。

値が大きいほど，受信者はどのメッセージだったか判断できていないことを意味する。


---

### (3) 相互情報量
観測によって減少した不確実性を表す。

本課題では，これを「情報量」として扱う。


---

### (4) 推定の曖昧さ
ハミング距離が最小となる候補が複数存在した回数を記録する。

曖昧さが増加するほど，受信者はメッセージを区別しにくくなる。


---

# 6. アルゴリズム
本シミュレーションでは，各ノイズ率について20,000回の試行を行う。

処理の流れを以下に示す。

① メッセージをランダムに選択する

↓

② 通信路でノイズを加える

↓

③ ハミング距離を計算する

↓

④ 最小距離のメッセージを推定する

↓

⑤ 正誤を記録する

↓

⑥ 混同行列を更新する

↓

⑦ 情報量を計算する

↓

⑧ 次のノイズ率で同様の処理を行う

この手順を，ノイズ率0.00から0.50まで繰り返す。

## 9.1 正答率
（accuracy_vs_noise.png を貼り付ける）
図より，ノイズ率が0付近では，ほぼ100%の確率で正しいメッセージを復元できていることが分かる。

しかし，ノイズ率が増加するにつれて正答率は徐々に低下した。

これは，受信したビット列が本来のメッセージから大きく変化し，異なるメッセージとの距離が近づくためである。

特に，ノイズ率が0.5付近では，受信データがほぼランダムとなるため，正答率は大きく低下した。


---

## 9.2 情報量

（information_vs_noise.png を貼り付ける）
図より，ノイズ率が小さいとき，条件付きエントロピーはほぼ0となり，相互情報量は約3bitとなっている。

これは，受信結果を見ることで，送信メッセージがほぼ一意に決定できるためである。

一方，ノイズ率が増加すると，条件付きエントロピーは増加し，相互情報量は減少した。

つまり，受信結果だけでは送信メッセージを十分に区別できなくなったことを意味している。

この結果は，本課題で定義した「情報とは不確実性を減少させるものである」という考え方と一致している。


---

## 9.3 推定の曖昧さ
（ambiguity_vs_noise.png を貼り付ける）
ノイズ率が小さい場合，最小ハミング距離となる候補はほぼ1つだけであった。

しかし，ノイズ率が高くなるにつれて，複数のメッセージが同じ距離となる場合が増加した。

これは，受信者がどのメッセージであるかを判断できなくなっていることを示している。

言い換えれば，情報が不足しているため，候補を十分に絞り込めていない状態である。


---

## 9.4 混同行列

（confusion_matrix.png を貼り付ける）

混同行列を見ると，ノイズ率が小さい場合には，対角成分に値が集中している。

これは，送信したメッセージが正しく推定されていることを意味する。

一方，ノイズ率が増加すると，対角成分以外にも値が分布するようになる。

つまり，異なるメッセージとして誤って推定される回数が増加している。

混同行列は，どのメッセージ同士が混同されやすいかを視覚的に確認できるため，通信性能を評価する上で非常に有効である。

# 10. 考察
本課題では，「情報とは，不確実性を減少させるものである。
」という定義を採用した。

シミュレーション結果を見ると，ノイズ率が小さい場合には，受信者は送信メッセージをほぼ完全に識別できた。

このとき，条件付きエントロピーは小さく，相互情報量は最大となる。

つまり，観測によってほとんど全ての不確実性が取り除かれている。

一方，ノイズ率が増加すると，受信者は正しいメッセージを推定できなくなる。

その結果，条件付きエントロピーは増加し，相互情報量は減少した。

これは，観測によっても十分な不確実性の減少が得られなかったことを意味する。

このことから，情報量とは単純にデータ量の多さではなく，「どれだけ候補を区別できるか」によって決まると考えられる。

例えば，16bitのデータを受信したとしても，ノイズによって内容がランダムになってしまえば，送信されたメッセージを識別することは困難である。

つまり，16bitというデータ量を受け取っていても，情報量は小さい。

逆に，少ないデータ量であっても，候補を一意に決定できれば，大きな情報を得たと言える。

この結果は，シャノン情報理論における「情報とは不確実性の減少である」という考え方とも一致している。

また，本課題ではハミング距離を用いてメッセージを推定した。

ハミング距離は，誤り訂正符号やQRコード，デジタル通信など，実際の情報通信システムでも広く利用されている。

そのため，本シミュレーションは情報理論の基本的な考え方を理解するだけでなく，実際の通信技術にも応用できる内容となっている。


# 11. 本研究と自身の研究との関連
現在，私は大学院において，文字画像を重畳したQRコード（Text QRコード）に関する研究を行っている。

一般的なQRコードは，高い読み取り性能を持つ一方で，格納されている情報を見た目から把握することはできない。

そこで，QRコード上に文字画像を重畳することで，格納情報を視覚的に理解しやすくする研究が行われている。

しかし，文字画像を重ねることでQRコードのモジュールが変化し，読み取り性能が低下するという問題が存在する。

私の研究では，
- データ語の最適化
- ドットサイズの最適化
- 焼きなまし法（Simulated Annealing）

などを用いて，
読み取り性能と視認性の両立を目指している。

本課題で扱った「情報とは，不確実性を減少させるものである。
」という考え方は，
QRコードにもそのまま当てはまる。

QRコードを読み取る前には，利用者は「どのような情報が格納されているか」を知らない。

しかし，QRコードを読み取ることで，URLや文字列が一意に決定され，利用者の不確実性は減少する。

一方，文字画像の重畳によって読み取り性能が低下すると，QRコードを正しく認識できなくなる。

これは，受信者（利用者）が正しい情報を取得できない状態であり，本課題で示した「情報量が減少する状態」と同じ考え方で説明できる。

このように，本課題で学んだ情報理論の基礎は，現在取り組んでいるQRコード研究にも応用できると考えられる。

# 13. まとめ
本課題では，「情報とは何か」という問いに対して，自分なりの定義を与え，数学的に定式化した。

本課題では，
> **情報とは，不確実性を減少させ，対象を区別可能にするものである。**

と定義した。

この考え方を確認するため，通信路シミュレーションを作成し，ノイズ率を変化させながら，
- 正答率
- 条件付きエントロピー
- 相互情報量
- 推定の曖昧さ

を評価した。

その結果，ノイズ率が増加すると，受信者はメッセージを正しく識別できなくなり，条件付きエントロピーは増加し，相互情報量は減少した。

つまり，受信者が得られる情報量は，「どれだけデータを受け取ったか」ではなく，「どれだけ候補を区別できたか」によって決まることが確認できた。

また，この結果は，シャノン情報理論の考え方とも一致しており，本課題で定義した「情報＝不確実性の減少」という考え方の妥当性を示す結果となった。

さらに，この考え方は，通信だけではなく，QRコード，画像認識，人工知能，医療診断，ロボット制御など，多くの情報処理分野にも応用できる。

本課題を通して，情報理論は単なる通信理論ではなく，「未知の対象をどれだけ正確に識別できるか」を数学的に扱う学問であることを理解することができた。
